# Final full-state application and interaction measurements

This completes the application scope in the original plan. The 2 ms target
continues to apply to complete model blocks divided by K. Application costs
add required checks and actual native state handoff; they are reported separately.
No application-specific drift limit is invented: the existing research equation,
field and near-zero criteria remain, and application acceptance limits are diagnostic.

## Prerequisites and immutable selection

Finish the existing four managed fits, exact CPU restores, every-output/own240
evaluations and both isolated CPU comparisons. Replicate promising bundled
recipes and the independently trained one-step control as specified in the
original plan. Freeze recipe, primary seed, all neural artifacts, execution
policy, normalization, sources and scene identities before reserved capture.
A seed is not reselected after reserved results. The temporal-cell seeds share
frozen learned pressure, flux, point and viscosity components; they are not
independent pretraining of those components.

Qualify the actual selected execution against its own exact CPU checkpoint.
Float64 execution requires complete physical-byte equivalence. A float32 map
changes rounding and requires a complete new every-horizon/own240 evaluation
for each selected model; the old composed K2 result cannot establish accuracy
for a different trained checkpoint. No pressure solve or corrective projection
may enter a candidate episode.

## Native research interface

The bounded transport uses the unchanged compiled Rheon probe and preserves
the original pressure gates. It qualifies startup, restored step8and eight
subsequent reference steps byte for byte on the odd grid and32³at16cells/metre.
All native processes must complete and reap. Reads and shutdown have finite
limits. The forecast consumer forbids numerical advance; each state setter
acknowledges zero numerical simulation steps.

The state setter is structural. Its cost is an actual research integration
cost, not certification of native physical acceptance or a shipping renderer.
Report that contract explicitly alongside numerical-reference pressure gates.
Offline equation/field checks remain independent and cannot become inference
inputs or corrective operations.

The application-mechanics qualification uses the real restored K2 cell at
K1/2/3/4diagnostic unroll lengths. This checks state transport and discarded-work
accounting, without claiming independently trained K1/K3/K4models, their accuracy,
or performance. Actual fitted models remain the measurement subjects below.

## Episodes and controls

Use all eight consumed development scenes, preserving both cell densities and
reporting the three small geometries and32³separately. Compare the frozen K1,
K2,K3,K4models with native PCG, the spectral numerical reference and the real
C107-pressure native control. Use five balanced serial CPU repeats, one thread,
batch one and core23; no competing numerical campaign runs during timing.

For each method and scene measure:

- A complete240-step steady episode, covering12/48/240accuracy diagnostics.
- A48-step interaction episode with an unannounced acceleration multiplier1.5
  after accepting physical step13. The old block receives only the old forcing;
  the next block receives the changed forcing. Discard all K-1unused pre-event
  states and count endpoint overshoot separately. Every generated state costs
  time even when discarded. The simulation advances only48accepted steps.

Native numerical controls use the same initial state, physical interval and
interaction clock. Count event state export, restart and upload when required
by the actual interface. C107 retains unchanged native gates and no fallback;
if it rejects, publish accepted steps, raw rejection and attempted cost, with
no fabricated completed-interval throughput.

An unsupported boundary change is a separate functional guard: invalidate the
unused block and stop before consuming step14. This does not establish support
for an untrained boundary condition and is not a48-step throughput success.

## Timing and evidence

Measure complete model calls, finite/shape/dtype checks, native state transfers,
acknowledgements, event reinitialization, final field/clock verification and
shutdown. Include all generation and discarded-block work. Keep loading,
compilation/cache preparation and initial native setup separately visible, with
explicit cold-episode amortization and actual peak RSS. Publish full-block
latencies, application seconds per physical second, median/p95/max and spreads.

Reference states and metrics never enter the measured forecast episode. Retain
predicted fields for deferred offline evaluation; record the associated memory.
Compute equation, P/V/T relative and absolute errors, divergence, boundary flux,
tracer mass/bounds, energy and diagnostic threshold times after the episode.
Do not include these independent ground-truth comparisons in application timing.
Document any export pauses used solely for offline numerical-control validation.

Each episode records actual model identity, event revision, timestamps, every
consumed state, total generated states, rejected blocks, event and endpoint
discard counts, native acknowledgement counts, all process custody and raw
failures. An incomplete episode has no completed-interval worst error or
throughput claim. Preserve every failure and publish both successful and failed
configurations in the final separate pressure and temporal frontiers.
