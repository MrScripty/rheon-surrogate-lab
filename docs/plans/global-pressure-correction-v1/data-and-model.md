# Dataset, split and one fixed model

This is a proposed lab data contract, **not a new Tuldok schema**. No arrays or
reserved targets have been generated by this design task.

## Physical problem and generation

Use a 3D uniform MAC grid in a stationary sealed rectangular box, zero wall-normal
face velocities, constant density, original RHS (never mean-shifted) and cell-zero
pressure gauge. Counts are 16³ for smoke, 32³ for full; physical extents vary by
geometry. Grid spacing is extents/counts in meters. No internal obstacles, viscosity,
free surface, variable density, moving walls or engineering-flow claims.

Every reference trajectory starts from zero velocity and a centered Gaussian
passive tracer with amplitude 0.25 and width 0.08 times the minimum box extent.
No tracer injection or clipping after initialization. Use unchanged public
velocity/tracer advection, followed by boundary-valid body acceleration and native
pressure projection; record the exact stage order in the implementation config.
Coordinates for forcing are normalized by each extent. The moving source uses
center `[.43+.13*sin(phi+t), .28+.06*cos(phi), .45+.13*cos(phi-t)]`, with physical
width 0.1 times minimum extent; direction `[.75*cos(phi+2t),1,.75*sin(phi+2t)]`.
`phi = (seed % 997)*.137`. Smooth forcing amplitude is 0.5 or 1.0 m/s²; declared
broadband component is 0.025 times smooth amplitude, deterministic per face/frame
using the trajectory source's integer mixer. Steady-source regime fixes center
and direction at t=0. Held-out pulsed regime multiplies moving forcing by
`1 + .5*sin(8*pi*t)`; it is absent from train/validation. Version these definitions
and test cross-process determinism; never rely on ambient RNG or file enumeration.

All suites use rho 1.25 kg/m³. Train/validation use dt=1/60 s. The regime suite
uses dt=1/90 s, amplitude 1.5 m/s² and pulsed forcing. This is a forcing/time-step
regime holdout, **not a Reynolds-number/turbulence generalization claim**.
Physical times and Courant numbers must be reported, including differing durations.

Generate reference pressures with Jacobi-PCG and independently verify a sample
with SGS-PCG and analytic cosine action. Qualification is the common contract in
acceptance.md. Capture each preprojection state, native pressure and previous
accepted pressure (zero at frame 0). Train targets for correction are
`p_ref[t] - p_base[t]`; do not expose current reference pressure as model input.
In teacher data `p_base` is previous reference pressure. Autonomous evaluation
uses the method's own last accepted pressure/state, including accepted fallback.
This teacher-state distribution difference is explicit and tested by rollouts.
Do not add training-time rollout data from validation or test.

Keep generator and verifier separate entrypoints. Verify reference residual,
rounded divergence, boundary compatibility and exact array hashes before admitting
a complete trajectory. If a reference fails, retain its ID/reason and stop that
preset; do not resample, drop the case or relax tolerances.

## Complete split reservation

`reservation.json` is the metadata-only source of split identities. Geometry IDs
resolve to extents below; a geometry hash includes counts, extents, origin, density,
boundary convention, units and canonical serialization, not only its name.

| ID | Extents xyz, m | Eligibility |
| --- | --- | --- |
| g0 | [1.0,1.0,1.0] | Train, validation, trajectory test, regime test |
| g1 | [1.2,1.0,0.8] | Train, validation, trajectory test |
| g2 | [0.8,1.2,1.0] | Train, validation, trajectory test |
| g3 | [1.0,0.8,1.2] | Train, validation |
| g4 | [1.4,1.0,0.6] | Geometry test only |
| g5 | [0.6,1.4,1.0] | Geometry test only |

Smoke has 12 train and 4 validation whole trajectories, each 24 frames. It reserves
four test trajectories per suite, each 96 autonomous frames. Trajectory-only test
reuses seen geometry/regime with fresh whole histories; geometry-only test uses g4/g5
with seen forcing; regime-only test uses g0 with unseen pulse/dt/amplitude. Distinct
suites separate causes rather than hiding them in one combined shift. Full reserves
48 train/12 validation (128 frames) and 8 tests per suite (600 frames) with new seeds.
No smoke test case is eligible for full training or validation.

All frames, crops, augmentations, generated restarts and duplicate derived files
inherit their parent trajectory's split. Whole seed sets are disjoint across all
partitions/suites/presets. Exact geometry separation is required for the geometry
suite; near-geometric variants outside the reserved table are prohibited in v1.
No shuffled-frame split, overlapping temporal windows or regenerated train seed
in test. No architecture/epoch selection from test. The new 100000+ seed namespace
is separate from all prior experiments; audit existing seed inventories before
implementation, not just this declaration. A new namespace alone is no leakage proof.

## Manifest and leakage checks

Proposed schema ID `rheon-global-pressure-v1` owns: complete status, lab/Rheon/patch
commit and source hashes, binary hash, preset, trajectory ID/seed/split/suite,
geometry hash/spec, forcing/regime IDs, rho/dt/units, frame indices/times, generator
config hash, reference settings, per-array layout/shape/dtype/bytes/SHA256 and
verification report. Arrays use explicit little endian `<f4` MAC velocity/tracer
and `<f8` cell RHS/pressure; x varies fastest, tensor adapters expose N,C,Z,Y,X.
Record actual row-to-trajectory mapping, never infer it from NPZ file order.

Every raw-array payload, not only its compressed container, has a hash. Validate
shapes/products before allocation, finite values, IDs/uniqueness, safe regular
paths, endian/layout, monotonic times, frame coverage and source closure. Publication
is exclusive into a new output directory; no success manifest for partial output.
Fresh-process reread verifies bytes and native RHS reconstruction.

Training receives only train/validation shards plus persisted development split.
Final-test manifest/arrays are not inputs and should not exist before freeze.
Normalization fits only train frames, recording exact parent IDs and frame counts;
validation never supplies statistics. Persist per-input RMS scales for residual,
previous pressure and each varying physical conditioning feature; positive finite
scales have training provenance. Zero-variance conditioning uses a declared constant
scale of 1 in its physical unit, not test-derived variance. Coordinates are analytic.

Before freeze: enforce group disjointness, hash lineage, duplicate RHS/velocity
payload detection and no final-test inputs. Reject a cross-split duplicate whole
trajectory. Exact zero-state/shared first-frame duplicates are tagged and reported,
not described as independent evidence. Require nontrivial frames in each holdout.
Near-duplicate similarity is reported by trajectory fingerprint (forcing+geometry+
seed+initial state) and sampled relative field distances; it is not a causal proof.
Perturb validation values and labels in a disposable fixture: normalization and
fixed-update trained weights must stay unchanged. Delete test sources entirely:
train/restore-dev must still succeed. Inject relabelled/cropped lineage duplicates:
split validator must reject at the lineage boundary.

## Selected architecture and fixed optimization

One eager Torch model: four encoder levels with widths [8,16,24,32], each two
3³ convolutions + SiLU with replicated padding; 2³ average pooling between levels;
after the fourth pool use two 3³ width-48 bottleneck convolutions. Add globally
average-pooled bottleneck features, broadcast back before decoding. For 16³ the
bottleneck is 1³; for 32³ it is 2³ plus the global path. Decoder uses nearest
upsampling to the recorded skip shape, concatenation and two 3³ convolutions
with widths [32,24,16,8]. A 1³ linear head emits a scalar pressure correction.
No batch normalization, dropout, attention, JIT, torch.compile or multiprocessing.

Input channels: residual `r=b-A p_base` / train residual RMS, previous gauge-fixed
pressure / train pressure RMS, analytic normalized x/y/z cell coordinates, and
broadcast hx/hy/hz/rho/dt in declared training-derived scales: **10 channels**.
Native full operator supplies r. Predicted correction is scaled by train pressure
RMS, converted to float64 and gauge-fixed by subtracting its first cell. Add it to
p_base. An exact-zero residual returns unchanged p_base without inference. Learned
zero/sign/scaling behavior is otherwise diagnostic, not guaranteed by construction.

Cap parameter count at 1,000,000 and serialized weights at 8 MiB; compute exact
counts before admission. Stored weights are finite numeric arrays plus an explicit
architecture/version/shape/dtype inventory, not executable pickle. Decoder/padding
shape checks and global-dependence tests must prove the actual implementation.
A local input perturbation must influence a distant output through the global path;
a zero-initialized head is unsuitable for that construction test.

Smoke: one thread, model/train tensors float32, native loss reductions float64,
batch 2 whole-frame samples chosen from train only, seed 20261014, exactly **200 Adam
updates**, lr 1e-3, betas (.9,.999), epsilon 1e-8, no weight decay, fixed sample-order
seed 20261015, gradient norm cap 1.0. No restarts, hyperparameter sweep, early stopping
or checkpoint choice. Save final update 200; log train every 20, validation at 0/200.
Validation is observational and cannot change the fixed update sequence.

Equal frame weighting is nested within equal trajectory weighting. Loss is
`0.5*||p_hat-p_ref||²/max(||p_ref||², eps_p²)` plus
`0.5*||A p_hat-b||²/max(||b||², eps_b²)` per frame.
`eps_p = 1e-6 * sqrt(cell_count) * train_pressure_RMS`,
`eps_b = 1e-6 * sqrt(cell_count) * train_rhs_RMS`; these are numerical denominator
floors, not solver tolerances. Training-only zero-scale data is rejected. Use the
actual finite-volume full operator coefficients, including gauge semantics;
verify the differentiable stencil and its gradient against native action and an
independent tiny hand-assembled anisotropic chain. The model can learn from labels
and residuals; analytic inverse coefficients cannot enter its inputs or weights.

Finite-difference checks on a tiny train fixture cover loss/gauge gradients. Native
operator/correction comparison covers all axes, walls and multiple aspect ratios.
After restore, pure model predictions must be bitwise equal on the same qualified
CPU runtime; native output tolerance is specified separately in acceptance.md.
