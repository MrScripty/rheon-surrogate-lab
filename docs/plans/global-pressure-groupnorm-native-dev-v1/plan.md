2. **Three substantive starting policies.** GN warm32 plus one fresh full p_base reset3000; previous-pressure-only full-budget Jacobi3000 (`temporal_full_budget`); zero-start Jacobi3000. Previous-pressure-only and the existing full-budget temporal baseline are exactly one comparator. Retain raw reference/GN/p_base/zero checks and short temporal32+reset3000 as fixed diagnostics. Do not double-count identical methods as independent evidence. There is no analytic or learned-SGS native path in this bounded action.
3. **Original physics remains authoritative.** Reconstruct original b from each captured preprojection MAC state and apply the full native operator including cell0. All starts/attempts use that same b and tolerance scale. Pass solver status and every common quality gate before accepting a staged pressure/velocity result. State is never advanced in this teacher-snapshot action.
4. **Fallback is numerical, not authority recovery.** Wrong artifact/source/receipt/data identity aborts before native work. Valid but numerically rejected proposals go to the full p_base path; failed warm work is discarded and charged before one fresh reset. A failed reset/resource/lifecycle obligation fails the declared complete diagnostic; it does not permit cropping or retry.
5. **Credential-free local route.** Existing files and native6 binary can support the proposed local diagnostic without Tuldok session renewal, Graph, preflight, grant or new Run. The current old wrapper rejects GN's distinct receipt, so it cannot simply be invoked or fed a relabeled receipt. A new narrow artifact adapter and its resource/conformance evidence are required. No credentials or source are changed now.
6. **Bounded work and honest timing.** One fixed serial pass, one native thread, 600s total wall, native per-case timeout at most60s and remaining total deadline; 1MiB request/512KiB response, observed4GiB high-water and complete32MiB report-output cap proposed. The fixed solver ceilings sum to at most386,048 capped iterations across32 cases. Timer omissions cannot become zero-cost checks; old native process wall includes all methods. Earlier restore inference is charged as a labeled historical/cross-execution observation, never a newly measured end-to-end candidate time or speedup.
7. **Keep later claims separate.** This action can establish only development one-step proposal/policy acceptance and iteration diagnostics. It cannot close autonomous rollout, held-out geometry/regime/final-suite, analytic comparison, resident/cold total solver speedup, conservation beyond instantaneous volume flux or GPU/full-training claims.
