Norms do not add as lengths when gradients point in different directions. The early term already includes its fixed 0.05 weight. Each reconstructed joint gradient matches the captured full gradient bit for bit. Separately backpropagating terms and then adding their float32 parameter gradients can differ because arithmetic order changes. The original 5e-6 check is preserved per case; these limitations concern the gradient diagnostic, not the model's 1e-6 pressure acceptance threshold. Small alignment differences should not be treated as causal evidence.
