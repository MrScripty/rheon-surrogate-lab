The correction is rescaled to pascals, given a zero-cell gauge, and added to the previous pressure. This page inspects inputs; it does not run the pressure network.

Array order, physical sizes and actual data

The order is [batch, channel, z, y, x]. X is fastest in the flattened array. A batch entry is a separate sample, not another spatial direction. This dense tensor contains samples with matching shapes; training handles differently shaped samples separately and accumulates their gradients.

Voxels have one shared edge length h: domain lengths are [Nx × h, Ny × h, Nz × h]. At 16 cells per metre, h = 0.0625 m. Increasing one axis adds voxels, preserving cubic cells.

Residual, previous pressure, spacing, density and time step use the saved training normalization. Position channels are physical cell centres in metres with unit scale 1 m. The table displays the actual float32 numbers passed to the network. Pressure residual means b − A × previous_pressure; reference solved pressure is a training target, not an input channel.

Load a JSON export from scripts/export_pressure_tensor.py to inspect recorded inputs. Without an export this page uses deterministic illustrative values, clearly labelled above. Shape support alone does not establish pressure accuracy.
